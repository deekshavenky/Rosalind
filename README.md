# Rosalind Solutions

My Python solutions to problems from [Rosalind](https://rosalind.info), a platform for learning bioinformatics through programming.

| ID | Problem | Concepts | Solution |
|---|---|---|---|
| [DNA](https://rosalind.info/problems/dna/) | Counting DNA Nucleotides | String counting | [dna.py](dna.py) |
| [RNA](https://rosalind.info/problems/rna/) | Transcribing DNA into RNA | String replacement | [rna.py](rna.py) |
| [REVC](https://rosalind.info/problems/revc/) | Complementing a Strand of DNA | Dictionaries, reverse complement | [revc.py](revc.py) |
| [FIB](https://rosalind.info/problems/fib/) | Rabbits and Recurrence Relations | Recurrence relations, loops | [fib.py](fib.py) |
| [GC](https://rosalind.info/problems/gc/) | Computing GC Content | FASTA parsing, functions | [gc.py](gc.py) |
| [HAMM](https://rosalind.info/problems/hamm/) | Counting Point Mutations | Hamming distance | [hamm.py](hamm.py) |
| [IPRB](https://rosalind.info/problems/iprb/) | Mendel's First Law | Probability, combinations, Mendelian genetics | [iprb.py](iprb.py) |

## Running a solution

Some scripts read the problem input from the keyboard (paste it in when prompted). Others read the dataset file downloaded from Rosalind, so place that file in the same folder before running:

```
python3 iprb.py
```

Solutions are added as I work through more problems.
